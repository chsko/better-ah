# Prices come from our own scans, with an import seam

Addons cannot reach the internet, so TSM relies on a desktop app that writes server-side price data into a helper addon. For v1 Better AH builds every price only from the player's own in-game scans, so there is nothing to install outside the game, and it is unclear whether Blizzard's public API covers Forever realms at all. The price database still accepts imported prices through one interface, so a companion app can be added later without reworking pricing.
