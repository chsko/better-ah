# Own auction window, in the game's native art style

Better AH opens its own window instead of adding tabs to Blizzard's auction house or docking a side panel. A "Blizzard UI" button toggles to the normal window and back. We chose this from a three-way prototype (branch `prototype/ui-placement`) because a sidebar of workflows and a detail panel that explains each price need more room than Blizzard's fixed frame. Unlike TSM's custom skin, the window is built from the Forever client's own frame templates, textures and fonts so it looks native.
